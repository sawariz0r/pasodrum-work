# M9-01 shell spike: Tauri 2 result

## How to run
1. `export PATH="$HOME/.cargo/bin:$PATH"; cd apps/desktop-tauri/src-tauri`
2. `TAURI_SIGNING_PRIVATE_KEY="$(cat ~/.tauri/pasodrum-spike.key)" TAURI_SIGNING_PRIVATE_KEY_PASSWORD="" cargo tauri build --bundles app` (the `dmg` target fails on this Mac, see 7b)
3. `cp -R "target/release/bundle/macos/Pasodrum Tauri.app" ~/Applications/ && open ~/Applications/"Pasodrum Tauri.app"` (loads http://localhost:4173; override with `PASODRUM_URL`)
4. Shell log: `~/Library/Logs/Pasodrum Tauri/shell.log`. Unattended probing: run the binary in `Contents/MacOS/` with `PASODRUM_PROBE=<js>` (evaluated on each page load; reports via the `probe` event into the log), `PASODRUM_PROBE_INIT=probe/init.js` (early console capture), `PASODRUM_UPDATE=1` (check, install and restart 5 s after launch). Probe scripts: `probe/common.js` + one scenario file.
