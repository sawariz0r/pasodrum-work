Rules — tabs, pins, files, link cards (M7)

Tabs (D-33)

RuleBoards
OrderMessages · Pins · Files, in every channel and DM. Built in: nothing to add or remove in M7, so no +. The header pin button goes; Pins is the tab.ChannelTabsM7
Open tabKept in the address (?tab=pins), so a reload or a shared link opens the same tab. Pins and Files replace the timeline and the composer; the draft waits in Messages.PinsTab, FilesTab

Pins

RuleBoards
WhoAnyone in the conversation, as in Slack (D-33). Not in an archived channel: it is read-only.MsgMenuPin
Pin, UnpinMore menu on a message: Pin or Unpin, last before Delete. No dialog, no toast: the glyph appears or goes.MsgMenuPin, MsgMenuUnpin
PinnedA small pin beside the time. No colour, no banner, no timeline row. A pinned message always shows its name line, so the pin has a place.PinnedMessage
Pins tabNewest pinned first: avatar, name, time, two lines of the message. Click jumps to it in Messages and it flashes, as replies do. Unpin on hover or focus. None: No pins yet.PinsTab(+Empty/Loading/JP/Dark)

Files

RuleBoards
ListEvery file and image sent here, newest first: thumbnail for images, type icon for the rest, name, who sent it, when. Images open the viewer; other files download. None: No files yet.FilesTab(+Empty/Loading/JP/Dark)
SourcePublic and client-space channels ask the server (contains_url). DMs and private channels: the server can’t see inside, so this device reads its own history; older files keep arriving at the end while it does (skeleton rows).FilesTabMore

Link cards

RuleBoards
WhichThe first link in a message only. Never in DMs or private channels: a preview sends the link to our server (D-11, D-33).LinkCardMulti
CardImage, site, title and one line of description, each on one line. No image: text only, same height.LinkCard(+JP/Dark), LinkCardNoImage
LoadingA skeleton of the same fixed height, so nothing below jumps. Nothing comes back: the plain link, no error.LinkCardLoading, LinkCardNone
