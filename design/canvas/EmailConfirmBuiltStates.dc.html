Send or help failed (app)

A failed send or help request adds one muted line under the action that failed and changes nothing else; a failed Send it again lands back on Confirm it’s you with the line.

Link page: can’t reach us · Yes, it’s me failed

The link page keeps one quiet look: the alert line is muted like in the app (no warning colours on client screens), the unreachable page has no pill because no contact is known.

No key held: an account from before D-38 with no confirmed device

With no usable key on our server, only what can work stays: Ask Jonas Berg (when there is a contact), Back and Start fresh.

Sign out from the last device: clients and Externals

Clients and Externals see this only when our server doesn’t hold their current key; they never see the recovery key line or New recovery key (staff keep SignOutWarn).

Reset and start fresh?: clients and Externals

Same dialog as ResetConfirm with no recovery key anywhere; after Reset the new key goes to our server and the conversation opens, with no save step.
