Rules — Translate a message (discovery)

Who and where

WhoTeam only: Owners, Admins, Members. Clients and guests never see Translate.
WhereWorkspace channels, team DMs and their threads. Never in a client space, and never where the outside mark shows (clients or guests in the conversation): their messages don’t leave our server.
Which messagesOther people’s text messages. Not your own, not files, not system rows.
IntoYour app language (English or 日本語). No setting.

The control

Hover barThe only entry point. Translate sits before More, and only when the message is in the other script from your language (kana/kanji vs Latin), checked on this device with no call. Pressed (accent) while the translation shows; pressing it again shows the original.
Not offeredMessages in another language with the same script as yours (e.g. Swedish for an English reader). No More-menu item: accepted, it would almost never be used.
KeyboardBoth are real buttons; the hover bar is reachable with focus, like React and Reply.

In place

TranslatedThe text is replaced by the translation. Mentions, inline code, links and formatting stay exactly as sent. One line under it: the translate glyph + Show original. No other label.
OriginalShow original swaps back; the line reads Show translation. Toggling is instant (cached).
TranslatingThe text pulses (D-20 shimmer) and the line shows the glyph + three dots; screen readers hear “Translating”. Reduced motion: text rests at 60 %.
FailedGlyph in red + “Couldn’t translate” · Retry, the same shape as “Not sent · Retry”. The original stays readable.
EditedAn edited message translates again the next time its translation shows.

Only you, only here

Nothing sentNo event, no reaction, no read change: the room, Element X and everyone else see the original. Standard clients are untouched (D-05).
CachePer message and per edit, in this browser only. Clearing site data forgets it; nothing syncs between devices.
RemovableDeleting the feature removes the button and the line; messages are unchanged (D-04).

One core, used again later

CoreOne shared translate(text or formatted text, into) used by every surface, so the same call serves the cases below. Translation runs on our side (/api/translate next to the invite service, caller checked like invites, OpenAI key only on the server, rate-limited).
Later, not drawnTranslate my draft before sending (composer, e.g. into Japanese for a client — the outside rule is revisited then). Docs and Boards: a task, a whole doc or one section.
